# DataScience-Projects
Mean Variance Analysis Using Numpy Project                                                     
📌 Project Overview                                                                                     

This project demonstrates how to perform basic statistical analysis using Python’s NumPy library.                   
It works on a numeric dataset and calculates important statistical values such as mean, variance, and standard deviation, both overall and along different axes.                                                
This helps in understanding how data behaves row-wise and column-wise in a structured array.

🎯 Objectives
Convert a 1D array into a 2D matrix                                                              
Compute overall statistical values                                                                               
Analyze data row-wise (axis=1)                                                       
Analyze data column-wise (axis=0)                                                                                                                                                            
Understand how NumPy simplifies data analysis
